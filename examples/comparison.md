# Compare deployment options

Illustrative scenario; no specific provider is being evaluated.

## Source

Hosted deployment takes little setup, keeps data offsite, and is operated by
the provider. Self-hosted deployment takes more setup, keeps data in your
environment, and is maintained by your team. Hybrid deployment takes more
setup plus integration work, keeps sensitive data local, and requires local
operations and integration maintenance.

## Structured result

| Option | Setup effort | Data location | Ongoing work |
|---|---|---|---|
| Hosted | Low | Offsite | Provider operates it |
| Self-hosted | Higher | Your environment | Your team maintains it |
| Hybrid | Higher + integration | Sensitive data local | Local ops + integration |

Shared criteria make the trade-offs visible. The source provides no prices,
team capacity, or weighting of the criteria, so it does not establish a winner.
