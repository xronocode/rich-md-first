# Report monthly activity

Illustrative scenario. All figures are synthetic event counts.

## Source

During one month, the team recorded 120 application events, 80 completed
checks, and 50 signed contracts. The report does not say whether these events
belong to the same users or when each user's process started.

## Structured result

| Event type | Count during the month |
|---|---:|
| Applications | 120 |
| Completed checks | 80 |
| Signed contracts | 50 |

The counts show activity during the period. They do not establish a cohort
conversion rate, the number of users who dropped out, or transitions between
these categories. A funnel or Sankey would add relationships absent from the source.
